// ❌ Error: ECONNREFUSED - Server not running
// ✅ Fix: Start backend: cd backend && npm start

// 2. Invalid supplier
// ❌ Error: "Invalid supplier"
// ✅ Fix: Use supplier_id from suppliers endpoint, not name

// 3. Insufficient stock
// ❌ Error: "Insufficient stock for product X"
// ✅ Fix: Check current stock from stock-report, reduce quantity

// 4. Missing fields
// ❌ Error: "Missing required fields"
// ✅ Fix: Ensure all required fields are present (supplier_id, invoice_number, items[], etc.)

// 5. Quantity must be > 0
// ❌ Error: "Quantity and price must be greater than 0"
// ✅ Fix: Use positive numbers for quantity and unit_price
